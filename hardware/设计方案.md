# Locker 智能储物柜电路设计方案

## 1. 系统总体架构

```
                ┌─────────────────────────────────────────────┐
                │                 主控板                       │
 2S锂电池组      │                                             │
 (7.4V, 带均衡线) │   ┌──────────┐    ┌──────────┐             │
      │         │   │ 电池保护  │───→│  3.3V    │──→ ESP32-C3 │
      ▼         │   │ HY2120   │    │ TPS54302 │    PRO MINI │
   J1(XH-3A)──→│   │ + 8205A  │    │  降压    │    (排母插座) │
                │   └──────────┘    └──────────┘      │      │
                │        │                            │      │
                │        ▼                            ▼      │
                │   ┌──────────┐    ┌──────────┐  ┌───────┐  │
                │   │ 12V 升压 │───→│ 电机驱动 │←─│ GPIO  │  │
                │   │ XL6019   │    │ DRV8870  │  │控制    │  │
                │   └──────────┘    └──────────┘  └───────┘  │
                │                        │                   │
                └────────────────────────┼───────────────────┘
                                         ▼
                                    12V 直流电机
                                   (开锁执行机构)
```

电源链路：**2S 锂电池 → 保护板（HY2120+8205A）→ 分两路**
- 常开 3.3V：TPS54302 降压，给 ESP32-C3 供电（已完成设计 ✅）
- 受控 12V：升压电路，仅开锁瞬间由 ESP32 使能，给电机驱动供电

设计理念：**12V 动力电源平时完全关闭**，待机时全板只有保护 IC（静态电流 100nA 级）、TPS54302（45µA）和 ESP32-C3 深度睡眠耗电，最大限度延长电池续航；开锁动作时才唤醒升压和电机驱动。

## 2. 12V 升压电路（Boost）

### 需求分析

- 输入：2S 锂电池 6.0V~8.4V（保护板过放截止 2.9V/节）
- 输出：12V，供锁具电机，工作电流约 0.5~1A，堵转峰值按 2A 设计
- 仅在开锁动作期间工作（每次数秒），需支持 MCU 使能控制

### 芯片选型

| 方案 | 型号 | 封装 | 开关电流 | 说明 |
|---|---|---|---|---|
| **首选** | XL6019（芯龙） | TO-263-5 | 5A | 引脚大、易手工焊接，立创库存充足，成本低 |
| 备选 | TPS61088（TI） | VQFN-10 | 10A | 效率高、体积小、同步整流，但 QFN 难手焊 |

选型理由：锁具电机为感性负载、启停冲击大，开关电流需留足裕量。XL6019 的 5A 开关限流对 12V/1.5A 输出（输入侧峰值约 3.5A）有足够余量，且 TO-263-5 封装适合手工焊接。不建议用 MT3608/SX1308 一类 2A 开关限流的小升压，带电机易触发限流。

### 设计要点

- 反馈电阻按 Vout = 1.25×(1+R上/R下) 设定 12V：R6=8.66kΩ、R7=1kΩ（均 1206 1%），得 11.9V
- 电感 L2：SMRH127-330M(f)，33µH/3A（12×12mm 屏蔽功率电感，C192704）
- 输出电容留足余量：2×22µF/25V（1206）+ 100nF，电机启停时抑制电压跌落
- 续流二极管 D1 选 SS34（3A/40V 肖特基，C9900023345）
- EN 引脚接 ESP32 GPIO，并加 100kΩ 下拉电阻，**确保上电默认关闭**
- 输入取自保护板之后（BAT_POS），使升压回路同样受过流/短路保护

## 3. 电机驱动电路（正反转）

### 芯片选型

| 方案 | 型号 | 封装 | 说明 |
|---|---|---|---|
| **首选** | DRV8870（TI） | HSOP-8(EP) | 6.5~45V 耐压，3.6A 峰值，IN1/IN2 控制正反转，VREF 设定限流，ISEN 低边电流检测 |
| 低成本备选 | RZ7899 | SOP-8 | 国产玩具电机驱动，3~25V，无电流检测输出 |

选型理由：
- VM 耐压 45V，12V 电机电源的启停尖峰有充足裕量（TB6612 仅 15V，裕量不足；DRV8837 仅 11V，不能用）
- IN1/IN2 两线控制：10=正转、01=反转、00=滑行、11=刹车，逻辑简单
- **限流设定**：I_TRIP = VREF / (10 × R_ISEN)。本设计 VREF 直接接 3.3V，R_ISEN = 0.22Ω（2512 封装 3W，C457148），限流 **1.5A**
- **ISEN 电流检测**：ISEN 引脚电压 = 电机电流 × 0.22Ω（0.22V/A），送 ESP32 ADC 做**堵转检测**——锁舌到位后电机堵转电流上升，固件据此关断，无需行程开关
- 内置限流兼作升压级的过载保护

### 设计要点

- 电机两端并联 100nF 电容（C16）抑制换向火花干扰
- 12V 输入端加 TVS（SMBJ15A）吸收电机感性尖峰
- VM 就近放 22µF + 100nF 去耦；PowerPAD 接 GND 散热
- 电机出线用 XH-2A 连接器（J2）

## 4. ESP32-C3 PRO MINI 插座（HW-953AB 核心板）

ESP32-C3 最小系统不在本板设计，采用成品 HW-953AB ESP32-C3 PRO MINI 核心板（引脚定义见 `esp32c3.png`），板上只做 **2.54mm 排母插座**：

- **两排 1×8P 2.54mm 直插排母**（H1/H2），对应核心板左右各 8 个引脚，手工焊接友好
- 注意 `esp32c3.png` 为核心板**背面视图**（USB-C 在图下方），实际使用时需左右翻转，**正视（元件面）引脚布局**：

| 左列（上→下） | 右列（上→下） |
|---|---|
| GPIO5 (A5) | **5V** |
| GPIO6 | **GND** |
| GPIO7 | **3.3V** |
| GPIO8 (SDA) | GPIO4 (A4) |
| GPIO9 (SCL) | GPIO3 (A3) |
| GPIO10 | GPIO2 (A2) |
| GPIO20 (RX) | GPIO1 (A1) |
| GPIO21 (TX) | GPIO0 (A0) |

- 核心板两端：**USB-C 在一端，PCB 天线在另一端**。布局时**天线端伸出主板边缘**（或天线区下方主板不铺铜、不走线），USB 端朝向板内侧并预留插线空间；若结构冲突，优先保证天线性能（固件可用 UART0 或 OTA 烧录）
- 3.3V、GND 从电源就近引到插座右列，3.3V 引脚旁加 100nF + 10µF 去耦
- 供电方式：本板 TPS54302 的 3.3V 直接接核心板 3.3V 引脚（绕过板载 LDO，效率最高）；核心板 5V 引脚悬空不接
- 核心板上的 BOOT / RESET 按键朝上外露，方便手动进入下载模式

## 5. 控制信号分配（GPIO 规划）

**核心板引脚约束**（依据 HW-953AB 引脚图）：

- **A0~A4 = GPIO0~GPIO4 = ADC1**，A5 = GPIO5 = ADC2（**ADC2 与 Wi-Fi 互斥**，模拟采样一律放 ADC1）
- **GPIO2/8/9 为 strapping 引脚**（GPIO9 兼 BOOT 键），不得挂下拉类负载，尽量不用作关键输出
- GPIO8(SDA)/GPIO9(SCL) 预留给 I2C 扩展（如未来加屏幕/传感器）
- GPIO20/21 为核心板丝印的 RX/TX，保留给调试串口

| 功能 | GPIO | 核心板丝印 | 方向 | 说明 |
|---|---|---|---|---|
| BOOST_EN 升压使能 | GPIO10 | 10 | 输出 | 高电平开启 12V，100kΩ 下拉，默认关闭 |
| MOTOR_IN1 | GPIO6 | 6 (MOSI) | 输出 | 电机正反转控制（可 PWM 调速） |
| MOTOR_IN2 | GPIO7 | 7 (SS) | 输出 | 电机正反转控制 |
| VSENSE_EN 采样使能 | GPIO5 | 5 (A5) | 输出 | 打开电池电压采样开关（仅数字输出，不用 ADC2） |
| BAT_VSENSE 电池电压 | GPIO4 | 4 (A4) | ADC1_CH4 | 分压后的电池电压 |
| MOTOR_ISENSE 电机电流 | GPIO3 | 3 (A3) | ADC1_CH3 | DRV8870 ISEN 检测电压（0.22V/A） |
| 调试串口 | GPIO20/21 | RX/TX | UART0 | 日志输出 |
| I2C（预留） | GPIO8/9 | SDA/SCL | — | 暂不使用 |

全部输出引脚均避开 strapping 引脚，上电时序安全。

**开锁动作时序**：置 BOOST_EN 高 → 延时 20ms 等 12V 建立 → 驱动 IN1/IN2 → 监测 ISEN 电压，堵转（电流超限）或超时（如 2s）即停 → IN1/IN2 归零 → BOOST_EN 拉低。

## 6. 电池容量检测

### 方案选择

2S 电池组的库仑计方案（需串联 2S 电量计芯片）成本高、选型少，采用 **电压估算法**：ESP32 通过分压电阻测量电池电压，查表换算剩余容量。锂电 2S 电压 6.0~8.4V 与电量存在稳定对应关系，对锁具场景的"低电提醒"功能精度足够。

### 电路设计

- 分压比：R上 100kΩ + R下 33kΩ（均 1206 1%），8.4V 满电时 ADC 处约 2.08V，处于 ADC 12dB 衰减量程内
- **采样开关**：分压网络常挂会持续耗电（8.4V/133kΩ ≈ 63µA），不可接受。用 AO3401（PMOS）做高边开关，PMOS 栅极经 100kΩ 上拉至 BAT_POS、经 2N7002（NMOS）下拉，GPIO 控制 2N7002 导通时 PMOS 打开开始采样。采样仅在唤醒期间进行，待机零功耗
- ADC 引脚对地加 100nF 电容，稳定采样值
- 固件侧：多次采样取中位数，按电压-容量曲线分段线性插值；6.4V 以下触发低电告警

## 7. 可靠性与保护设计汇总

| 风险 | 措施 |
|---|---|
| 电池过充/过放/短路 | HY2120-CB + 8205A（已实现） |
| 12V 母线空耗 | Boost 平时关闭，EN 下拉默认关断 |
| 电机堵转烧毁 | DRV8870 限流（VREF=3.3V，R_ISEN=0.22Ω → 1.5A）+ ISEN 堵转检测 + 固件超时 |
| 电机感性尖峰 | 电机端 100nF + 12V 母线 TVS |
| ESP32 上电误动作 | 所有使能/驱动引脚加确定电平（下拉），固件初始化后再输出 |
| 低电量无法开锁 | 电压检测低电告警；HY2120 过放截止前留裕量 |
